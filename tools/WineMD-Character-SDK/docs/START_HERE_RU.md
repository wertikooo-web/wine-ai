# С чего начать

1. Откройте `00_reference/master_character_source.png`.
2. Используйте `01_art_pipeline/layer_map.png` как карту разбиения.
3. Соберите PSD по `02_psd_spec/PSD_LAYER_TREE.md`.
4. Дорисуйте скрытую геометрию по `02_psd_spec/HIDDEN_GEOMETRY.md`.
5. Импортируйте части в Rive.
6. Постройте кости по `03_rive/bone_scheme.png`.
7. Создайте State Machine по `03_rive/STATE_MACHINE.md`.
8. Проверьте MVP: Idle, Speaking, Blink, Present Wine.
9. Экспортируйте `winemd-sommelier.riv`.
10. Подключите файл через код из `05_runtime`.
