# WineMD Character SDK

Production-oriented starter repository for a reusable animated 2D sommelier in WineMD.

## Included
- master reference and approximate transparent cutout;
- layer map and PSD specification;
- bone scheme and Rive state machine;
- animation library;
- TypeScript runtime controller;
- WineMD visual-event contract;
- prompts for Claude Code and Codex;
- Russian step-by-step documentation.

## Important
A genuine layered PSD and binary `.riv` cannot be reconstructed perfectly from one flattened PNG. Hidden geometry must be drawn and the rig must be assembled in an editor. This repository specifies that work reproducibly.

Start with `docs/START_HERE_RU.md`.
