# Knowledge retrieval

Knowledge retrieval augments realtime conversation through tools. It is not a mandatory stage between microphone input and audio output and does not own session or generation lifecycle.

Use confirmed indexed or structured sources. Empty knowledge and no-match results are valid outcomes. Fall back safely when semantic search is unavailable and never fabricate wine facts.

When changing search, tools, embeddings, KOS, or publication paths, inspect actual callers, payloads, persistence, and tests. Confirm that ingested data is really reachable from the assistant answer path before claiming integration is complete.
