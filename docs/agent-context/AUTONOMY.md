# AUTONOMY.md

## Read-only requests

For explanation, audit, diagnosis, comparison, or planning, inspect the required materials and report findings without changing files or external systems.

## Local implementation requests

For an explicit request to build, change, migrate, or fix:

- create or use an isolated branch;
- change only task-related files;
- run non-destructive targeted checks;
- update documentation when contracts or architecture change;
- open or update a draft pull request when requested.

## Explicit confirmation required

Stop before deployment, merge, production database writes, data deletion, access or OAuth changes, package publishing, purchases, or material scope expansion.

## Stop rule

Finish when the agreed scope is implemented, relevant checks have passed or their limitation is reported, the final diff has been reviewed, and another tool cycle would not materially reduce risk.
