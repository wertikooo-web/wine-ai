## Работа с задачей

- Для анализа, проверки, объяснения и плана изучай материалы и сообщай результат без правок.
- Для запроса изменить, построить или починить вноси локальные изменения и запускай неразрушающие проверки без лишнего согласования.
- Для необратимых действий, production-записей, deploy, merge, доступа и заметного расширения scope требуется явное подтверждение.
- Используй код, тесты, HTML, схемы и контракты как основные референсы. Markdown-описание не заменяет артефакт.

## Навыки пользователя
