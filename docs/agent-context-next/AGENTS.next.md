# AGENTS.next.md

## Назначение

WINE AI — независимый realtime-продукт: голосовой цифровой эксперт по винам Молдовы для устройства, сайта и виджета. Репозиторий должен запускаться, тестироваться и развиваться без зависимости от соседних проектов.

## Как собирать контекст

1. Прочитай `PROJECT.md`.
2. По типу задачи выбери один маршрут в `CONTEXT_MAP.md`.
3. Загрузи только указанные доменные инструкции, контракты и реальные артефакты.
4. Перед изменениями примени `AUTONOMY.md`.
5. Перед завершением примени `VERIFICATION.md` и `DEFINITION_OF_DONE.md`.

Не загружай весь каталог инструкций заранее. Код, тесты, схемы и макеты имеют приоритет перед их пересказом в Markdown.

## Инварианты

- Не создавай импортов, workspace, submodule или symlink за пределы репозитория.
- Не добавляй сущности детской игрушки: родительский контроль, детские профили, игры, загадки и истории.
- Один пользовательский ход имеет один авторитетный lifecycle. Устаревший `generationId` не влияет на новый ход.
- Каждый изменяемый lifecycle-state имеет одного владельца.
- Не печатай и не сохраняй секреты. Не сохраняй реальное аудио без явной настройки.
- Не выдумывай вина, производителей, награды, цены и винтажи.
- Не объединяй изменения провайдера, транспорта, RAG, персоны и аудиоконтура без прямой необходимости.

Подробные архитектурные ограничения находятся в `INVARIANTS.md`. Не дублируй их в новых файлах.

## Критерий работы

Выбери наименьшее локальное изменение, которое устраняет доказанную причину и сохраняет существующие контракты. Проверяй гипотезы по коду, тестам и наблюдаемому поведению.

## Остановка

После каждого результата оцени, достаточно ли данных для ответа или завершения правки. Остановись, когда выполнен согласованный scope, прошли относящиеся к нему проверки и дальнейшие циклы не снижают существенный риск.

Не запускай deploy, merge, запись в production DB, изменение доступов или публикацию пакета без отдельного явного запроса.
