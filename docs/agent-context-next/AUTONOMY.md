# AUTONOMY.md

## Без изменений

Для запросов объяснить, проверить, диагностировать, сравнить или спланировать изучи нужные материалы и сообщи результат. Не меняй файлы и внешние системы, если пользователь не просил об этом.

## Локальные изменения

Для запросов изменить, построить, переписать или починить внеси минимальные локальные изменения в рамках задачи и запусти неразрушающую проверку без предварительного согласования.

Разрешено самостоятельно:

- читать код, тесты, документацию и конфигурацию без значений секретов;
- создавать рабочую ветку;
- менять относящиеся к задаче файлы;
- запускать unit, syntax, lint и smoke-проверки;
- открыть draft pull request с полным описанием результата.

## Требуется подтверждение

Остановись перед deploy, merge, production DB write, удалением данных, покупкой, публикацией пакета, изменением доступов, OAuth/MCP-настроек и существенным расширением scope.

## Правило остановки

Решай запрос за наименьшее полезное число циклов инструментов, сохраняя корректность. После каждого результата проверяй, можно ли уже завершить задачу. Если данных недостаточно, используй самый узкий следующий шаг.
