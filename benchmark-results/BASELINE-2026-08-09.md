## Known production dependency hit

The `answerability_check` grader and part of the web fallback depend on the
Gemini API. On 2026-08-09 the linked Gemini project returned
`429 RESOURCE_EXHAUSTED` ("prepayment credits are depleted"), so the
answerability gate resolved to `no_evidence` / `answerability_check_error`
(fail-closed) for factual rows. This suppresses `answerable` and lowers the
pass rate; it is an external billing condition, not an Answer Audit defect.
Rerun after credits are restored with:

```bash
AUDIT_BASE_URL=https://wine-ai-realtime-production.up.railway.app npm run benchmark:quality
```
